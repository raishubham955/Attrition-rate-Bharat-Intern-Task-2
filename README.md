# Attrition Rate Analysis

This repository contains HR employee attrition data as well as a simple task manager website. It now also includes a basic customer relationship manager (CRM) to track contacts.

## Contents

- `WA_Fn-UseC_-HR-Employee-Attrition.csv` - Dataset used for attrition analysis.
- `Attrition Rate Analysis.pbix` - Power BI dashboard file.
- `Dashboard.png` - Screenshot of the dashboard.
- `task_manager/` - Simple web-based task manager.
- `crm/` - Simple web-based customer relationship manager.

## Task Manager

The `task_manager` folder contains a small website for managing personal tasks.
Open `index.html` in a browser to add, complete or delete tasks. Tasks are stored in
local storage so they persist between sessions.

## CRM

The `crm` folder provides a minimal CRM for storing customer contact details in the browser. Open `index.html` to add, edit or remove customer records. Data is saved in local storage for persistence between sessions.
