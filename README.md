# Attrition Rate Analysis

This repository contains HR employee attrition data as well as a simple task manager website.

## Contents

- `WA_Fn-UseC_-HR-Employee-Attrition.csv` - Dataset used for attrition analysis.
- `Attrition Rate Analysis.pbix` - Power BI dashboard file.
- `Dashboard.png` - Screenshot of the dashboard.
- `task_manager/` - Simple web-based task manager.

## Task Manager

The `task_manager` folder contains a small website for managing personal tasks.
Open `index.html` in a browser to add, complete or delete tasks. Tasks are stored in
local storage so they persist between sessions.
